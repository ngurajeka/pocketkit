# Bundled font

`AtkinsonHyperlegible-Bold.ttf` is Atkinson Hyperlegible Bold by the Braille
Institute of America, from the [Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/atkinsonhyperlegible).
It is licensed under the SIL Open Font License 1.1 (`OFL.txt`), **not** under
this repository's MIT license.

It's shipped unmodified inside every muOS app (as `font.ttf`, with the license
as `font-OFL.txt`) because muOS doesn't have MinUI's UI font. The OFL allows
bundling it with software as long as the license travels with it, it isn't sold
on its own, and modified versions don't use the reserved name.
